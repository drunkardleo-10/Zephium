# Actual-application foreground rendering qualification

Status: native ownership seam implemented; actual desktop driver and native
witness remain pending. No RAF, foreground preservation or commercial-site
success is claimed by this document yet. The prior standalone evidence and its
event-loop limitations remain in [macos-rendering-readiness.md](macos-rendering-readiness.md).

## Release-excluded ownership checkpoint

`native-agentic-foreground-probe` inherits the existing optimized-build refusal.
Only `probe-harness` exposes the closed browser-port diagnostic request. Other
implementations return Unsupported. Default Browse and production Work builds
do not compile the diagnostic contract, native surface, watchdog or fixtures.
This is not the eventual product rendering-lease API or a model tool.

Acquire, Poll and Retire bind the complete existing ContextJoin. Admission uses
the normal native task permit and one-shot request-bound callback, not another
queue or browser port. Synchronous refusal transfers no completion obligation;
an accepted discarded task settles Failed exactly once. Capacity and shutdown
sealing are shared with ordinary context operations.

Acquisition requires the sole exact native cohort member, an ephemeral owned
context, exactly Observe/Navigate capabilities, the fixed loopback rendering
fixture, stable completed navigation, and no prior semantic invocation or
pending native operation. The acquisition opportunity is consumed before
native preparation, including DeferredForeground. Navigation/recovery and other
lifecycle expansion are then refused; only cancellation and close remain.

The same existing WKWebView is reparented into one opaque fixed 1280×800 public
NSWindow. It is not a new renderer or capacity class. The hidden presentation
owner is retained by AgentOwnedContext before further fallible work or native
presentation. The surface cannot become key/main and ignores mouse input.
Existing active/visible application, key window, main window and first
responder must match the exact original human surface. No bootstrap, activation,
focus restoration, private SPI, scheduling-policy change, event pump or page
script is introduced.

The native lease has one original five-second admission deadline. A single
coalesced 50 ms main-queue watchdog revalidates foreground/deadline ownership
without resetting it; actual servicing is subject to the normal application
event loop and the existing dispatch-timer leeway. This is not a hard realtime
wall-clock guarantee. Every semantic dispatch and completion also revalidates
the exact owner. Revocation hides/restores on that main-thread step and retains
DeferredForeground/Expired honestly even if the watchdog noticed it before the
driver did. Only eight initial-scope invocations at the unchanged default
runtime budget are accepted.

Retirement hides before restoring the exact original parent/frame and does not
repair or reacquire human focus. Cleanup compares the current human owners
before/after restoration, retains sticky failure, and waits for the exact weak
auxiliary-window owner to drain. Close cannot remove the context or release its
capacity before that drain. Forced process shutdown retains an undrained cohort
and refuses clean closure. Native resource audits count actual visible surfaces;
zero known bindings/reservations cannot conceal a live diagnostic owner.

## Deterministic boundary

The engine tests cover foreground fact conjunction, fixed finite unclipped
geometry, sticky cleanup failure, exact one-shot deferral/failure settlements,
discarded accepted dispatch, native capacity saturation, synchronous rejection,
post-seal refusal, fixed fixture/scope and sample ceilings. The architecture gate
rejects activation/event-pump/scheduling hacks, lost feature gates, raised bounds,
missing owner publication/restoration, and bypassed native admission.

Checkpoint gates passed: engine library 486 tests; strict all-target engine
Clippy with `native-agentic-foreground-probe`; ordinary `agentic-browser` check;
the new foreground architecture adversary; both agentic/controller architecture
commands including hostile semantic JavaScript smoke; workspace fmt and diff
checks. These are deterministic/build results, not native rendering evidence.

The next witness must use the normal isolated Zephium desktop startup and Tauri
event loop with bundled assets, no provider or external site, and no implicit
application activation. Admission without actual user-owned foreground is
DeferredForeground, not a failed rendering measurement. A successful measurement
must additionally prove exact current-document markers and native/profile/
listener/port/application cleanup. No native attempt has run on this seam yet.
