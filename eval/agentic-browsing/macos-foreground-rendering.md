# Actual-application foreground rendering qualification

Status: native ownership seam and isolated actual-desktop driver implemented;
native witness remains pending. No RAF, foreground preservation or commercial-site
success is claimed by this document yet. The prior standalone evidence and its
event-loop limitations remain in [macos-rendering-readiness.md](macos-rendering-readiness.md).

## Release-excluded ownership checkpoint

`native-agentic-foreground-probe` inherits the existing optimized-build refusal.
Only `probe-harness` exposes the closed browser-port diagnostic request. Other
implementations return Unsupported. Default Browse and production Work builds
do not compile the diagnostic contract, native surface, watchdog or fixtures.
This is not the eventual product rendering-lease API or a model tool.

Acquire, Poll and Retire bind the complete existing ContextJoin. Admission uses
the normal native task permit and one-shot request-bound callback, not another
queue or browser port. Synchronous refusal transfers no completion obligation;
an accepted discarded task settles Failed exactly once. Capacity and shutdown
sealing are shared with ordinary context operations.

Acquisition requires the sole exact native cohort member, an ephemeral owned
context, exactly Observe/Navigate capabilities, the fixed loopback rendering
fixture, stable completed navigation, and no prior semantic invocation or
pending native operation. The acquisition opportunity is consumed before
native preparation, including DeferredForeground. Navigation/recovery and other
lifecycle expansion are then refused; only cancellation and close remain.

The same existing WKWebView is reparented into one opaque fixed 1280×800 public
NSWindow. It is not a new renderer or capacity class. The hidden presentation
owner is retained by AgentOwnedContext before further fallible work or native
presentation. The surface cannot become key/main and ignores mouse input.
Existing active/visible application, key window, main window and first
responder must match the exact original human surface. No bootstrap, activation,
focus restoration, private SPI, scheduling-policy change, event pump or page
script is introduced.

The native lease has one original five-second admission deadline. A single
coalesced 50 ms main-queue watchdog revalidates foreground/deadline ownership
without resetting it; actual servicing is subject to the normal application
event loop and the existing dispatch-timer leeway. This is not a hard realtime
wall-clock guarantee. Every semantic dispatch and completion also revalidates
the exact owner. Revocation hides/restores on that main-thread step and retains
DeferredForeground/Expired honestly even if the watchdog noticed it before the
driver did. Only eight initial-scope invocations at the unchanged default
runtime budget are accepted.

Retirement hides before restoring the exact original parent/frame and does not
repair or reacquire human focus. Cleanup compares the current human owners
before/after restoration, retains sticky failure, and waits for the exact weak
auxiliary-window owner to drain. Close cannot remove the context or release its
capacity before that drain. Forced process shutdown retains an undrained cohort
and refuses clean closure. Native resource audits count actual visible surfaces;
zero known bindings/reservations cannot conceal a live diagnostic owner.

geometry, sticky cleanup failure, exact one-shot deferral/failure settlements,
discarded accepted dispatch, native capacity saturation, synchronous rejection,
post-seal refusal, fixed fixture/scope and sample ceilings. The architecture gate
rejects activation/event-pump/scheduling hacks, lost feature gates, raised bounds,
missing owner publication/restoration, and bypassed native admission.

Checkpoint gates passed: engine library 486 tests; strict all-target engine
Clippy with `native-agentic-foreground-probe`; ordinary `agentic-browser` check;
the new foreground architecture adversary; both agentic/controller architecture

checks. These are deterministic/build results, not native rendering evidence.

The next witness must use the normal isolated Zephium desktop startup and Tauri

listener/port/application cleanup. No native attempt has run on this seam yet.

## Actual desktop driver checkpoint

The explicit `macos-work-rendering-probe` desktop feature uses the existing
Tauri setup, trusted chrome startup gate, engine event sink and normal run/shutdown
coordinator. There is no replacement NSApplication loop or IPC command. The
build refuses optimized/non-macOS targets, ordinary Work/lab/staging feature
combinations, a development server, or a missing/wrong configuration override.
The exact identity is `app.zephium.work-rendering-probe`, titled **Zephium Work
Rendering Probe**. Runtime also refuses any existing nonempty diagnostic data
root; it never deletes or restores a prior profile/session to make a run start.

After trusted chrome is mapped, the desktop independently verifies that its
exact native `main` window is already the active application's key/main surface
with a responder. Missing foreground yields normal `DeferredForeground` without
allocating a Work context, fixture or presentation. Admission itself never
activates Zephium. The driver retains the original human window/responder before
constructing Work so construction cannot silently redefine that baseline.

One generated ephemeral profile receives the fixed content policy and exact
loopback document through the production owned-context port. The fixed driver
validates phase, operation, context/document epoch, policy generation, semantic
correlation and shutdown audit identity. Its bounded four-entry mailbox fails
closed on overflow; no receipt is evicted. The only rendering operations remain
Acquire/Poll/Retire for that exact context. There is no public-site, credential,
keychain or provider dependency, and no arbitrary page script capability.

A single coalesced 25 ms normal-main-queue driver timer advances the state
machine. Eight fresh initial-budget samples are eligible at offsets
0/50/100/200/400/800/1600/3200 ms from acquisition; these are bounded observation
opportunities, not sleeps or a site readiness policy. The original native
five-second presentation lease remains independent. The whole driver has a
15-second measurement budget and a separate five-second cleanup budget, subject
to normal event-loop/timer servicing. One current-document sample must contain
all exact complete/load/microtask/timer controls plus the RAF reveal for a
positive provisional result. This browser port does not expose native finish
flags, so the new report does not claim to observe them.

Retirement precedes exact Close and a sealed audit requiring all nine native
resource classes to be zero. Later cleanup failure is separate from the primary
measurement outcome. The fixture worker/listener, driver, profile leases and
port are retired before reporting. Exit requested during a measurement is
deferred only while this bounded cleanup runs on the real event loop. No focus
is restored if a human changes it. A context-bound weak witness for the exact
page, auxiliary window and ephemeral native data store owns no resources and
must drain after the ordinary application/engine shutdown before the final
`qualified=true` line is possible. A positive sample or zero logical cohort
alone is not full native qualification.

Output is content-free: bounded sample elapsed time/node count/control and RAF
booleans; provisional outcome/cleanup/ownership/cohort/listener fields; then
normal-shutdown and exact-native-weak-drain closure. Deferred admission or a
negative rendering window can close normally without claiming qualification.
These checks do not establish background rendering, public-commerce readiness,
authenticated browsing, or a generally usable open-objective agent.

New deterministic tests cover reordered/stale/wrong-context rendering replies,
semantic generation and ordinary-audit substitution, sticky mailbox saturation,
all nine nonzero resource classes, exact isolated configuration and refusal of
prior session state. Mechanical adversaries reject custom loops/focus commands,
unbounded mailboxes, dropped exact phase checks, skipped weak closure and missing
fresh-root enforcement. The ordinary desktop's existing native chrome setup is
unchanged; this seam adds no private rendering SPI.

Checkpoint gates: engine library 490 tests; two isolated desktop configuration
